אתר שיר אופיר - הוראות עריכה

פותחים index.html בדפדפן. יש לשמור על כל התיקייה יחד.

תמונות:
images/shir-photo.webp - התמונה האישית
images/product-01.webp עד images/product-30.webp - תמונות המוצרים

כדי להחליף תמונה, שמרו תמונה חדשה באותו שם ובאותו פורמט WEBP בתוך תיקיית images. אפשר להמיר PNG/JPG ל-WEBP בתוכנת עיצוב.
אם רוצים לשמור תמונה כ-JPG או PNG, עדכנו גם את סיומת הקובץ בשורת src המתאימה ב-index.html.

טקסטים, שמות מוצרים ומחירים: עריכה בקובץ index.html באמצעות עורך טקסט.
צבעים, ריווחים ועיצוב: style.css
התנהגות הניווט: script.js

החנות כרגע להדגמה בלבד, ללא סליקה או הורדת קבצים בתשלום.
